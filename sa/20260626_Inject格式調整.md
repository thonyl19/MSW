第一層預設 GroupName 第二層才是指定注入對象
注入對象有以下類型 
bool: 直接以 switch /checkbox 呈現
array: 以複選 checkbox 做呈現 , 並注入對象
object: 以 key 選項名稱 , 將值注入對象
``` json
{
    "inject" : {
        
        "Basic" :{
            "Setting.CheckOutSet.OperInspInfo": {
                "檢驗項目資訊-1": _form.form1
            },
        },
        "Case1":{
            'Setting.CheckOutSet.OperInspInfo.Insp_Match':true,
            'Setting.CheckOutSet.OperInspInfo.NCR_Hold':[true,false],
            'Setting.CheckOutSet.OperInspInfo.OperInspSet.Ext.SYSTEM_JUDGMENT':{"True":"T","False":"F"},
        }

    }
}
```

之前的處理方法  是注入 , 但在處理上  只能一個對一個 ,如果是複數情形就有點不好解決 , ex: 模擬特定按鈕是否能顯示,但它需要 兩個參數{A=T,B=F} 符合 才能作動 ,原本的注入作法就不容易解法 , 所以我想要實作類似非同步回呼的方式 ,將需要處理的對象取回當 $d 傳 ,再進行操作

``` js
"inject" : {
    "Basic" :{
        "Setting.CheckOutSet.OperInspInfo":($d) {
            $d.A = 'T';
            $d.B = 'F';
        }
    },
},
```
